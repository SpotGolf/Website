SpotGolf is open source, and all support happens in GitHub issues. Open an issue to ask a question, report a bug, or request a feature. You need a free [GitHub account](https://github.com/signup) to open an issue.

## Pick the right project

| Project | Open an issue for |
|---|---|
| [SpotGolf](https://github.com/SpotGolf/SpotGolf/issues/new) | The iPhone and Apple Watch app: shot tracking, swing and putt detection, scores, iCloud Sync, Putt Data Sharing, and privacy questions |
| [CourseData](https://github.com/SpotGolf/CourseData/issues/new) | A course that is missing, or a course map that is wrong (tees, greens, hazards, hole numbers) |
| [CourseBuilder](https://github.com/SpotGolf/CourseBuilder/issues/new) | The macOS app that builds course maps |
| [CourseDataSwift](https://github.com/SpotGolf/CourseDataSwift/issues/new) | The Swift package for reading course data |
| [SensorSources](https://github.com/SpotGolf/SensorSources/issues/new) | The Swift package for watch and phone sensors |

If you are not sure which project to pick, use [SpotGolf](https://github.com/SpotGolf/SpotGolf/issues/new).

## Open an issue

1. Sign in to GitHub.
2. Click the project's link in the table above.
3. Search the project's [open issues](https://github.com/SpotGolf/SpotGolf/issues) first. If someone already reported the same problem, add a comment to that issue instead.
4. Write a short title that names the problem, such as "Putts not detected with a left-handed grip".
5. Fill in the details (below) and click **Create**.

We reply in the issue, and GitHub emails you when we do.

## What to include

| Detail | Example |
|---|---|
| What you did | Started a round and hit a tee shot on hole 1 |
| What you expected | The shot is marked on the map |
| What happened | No shot was marked |
| SpotGolf app version | 0.16.0 (found in Settings) |
| iPhone and Apple Watch models | iPhone 17, Apple Watch Series 11 |
| iOS and watchOS versions | iOS 27.0.2, watchOS 27.0.2 |
| Course name, for course problems | Riverside Golf Club, hole 7 |
| Screenshots | Drag them into the issue |

## Keep private data out

Issues are public. Do not post your email address, phone number, or home address in an issue. If the app's log or a screenshot shows a location you want to keep private, remove it before you post.
